A two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint" bounty: a To: line naming who the unsent message was meant for, and the message itself, exactly as it was typed and never sent.

## Run it

```sh
python3 main.py
```

It writes the confession to `/output/entry.txt`.
